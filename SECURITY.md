# Segurança

Para reportar uma vulnerabilidade, **não abra uma issue pública**. Use o recurso
“Report a vulnerability” na aba Security deste repositório (relato privado do GitHub).

Inclua a versão, o sistema operacional e os passos para reproduzir. Nunca envie dados reais de
projetos: use o projeto de exemplo.

O modelo de ameaças e os limites conhecidos estão no README, seção “Limites de segurança”.
